# pitch-plugin

A Claude Code plugin marketplace holding one plugin: **pitch**, for applying to design roles by building an on-brand prototype for the company instead of sending a resume.

```
claude plugin marketplace add SonwaneyY/pitch-plugin
claude plugin install pitch@pitch-plugin
```

Then, from any folder where you want the work to land:

```
/pitch <company> <job posting url>
```

See [pitch/README.md](pitch/README.md) for the stages, what each produces, and what it reuses.
